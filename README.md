# TrendVault (ShoppinggWebSite) 🛍️

A modern, responsive e-commerce web application for lifestyle, tech gadgets, and desk setup gear.

## ✨ Features

- **Responsive Grid Layout**: Beautiful modern UI built with Tailwind CSS.
- **Dynamic Category Filtering**: Filter between Audio, Desk Setup, Wearables, Photography, or All.
- **Live Search**: Instant product name and description filtering.
- **Smart Sorting**: Sort products by Popularity, Price (Low/High), and Top Rated.
- **Interactive Slide-over Cart**:
  - Live item quantity counter & badge
  - Real-time subtotal & total calculation
  - **Promo Code System**: Apply `SHIPHYPE20` for 20% off or `WELCOME10` for 10% off
  - Persistent state powered by `localStorage`
- **Simulated Checkout Flow**: Complete purchase modal with generated order tracking ID.
- **Toast Notifications**: Interactive feedback on every user action.

## 🚀 Quick Start

No build tools or Node.js environment required! Simply open `index.html` in your browser:

```bash
# Clone the repository
git clone https://github.com/NoneButACoder/ShoppinggWebSite.git

# Navigate to directory
cd ShoppinggWebSite

# Open directly or serve with any static server
# (e.g. VS Code Live Server or Python http.server)
python -m http.server 8000
```
